# Security policy | سیاست گزارش امنیتی

## Report privately / گزارش محرمانه

Please do not disclose vulnerabilities, license-related findings, credentials or customer records in a public issue. Contact [official support](https://t.me/anbarkhanir) privately and state that you are reporting a security concern. Describe the affected version and general impact first. Agree on a private channel before sending sensitive technical evidence.

لطفاً آسیب‌پذیری، یافته مرتبط با لایسنس، اطلاعات ورود یا داده مشتری را در Issue عمومی منتشر نکنید. با [پشتیبانی رسمی](https://t.me/anbarkhanir) خصوصی تماس بگیرید و موضوع را «گزارش امنیتی» اعلام کنید. ابتدا نسخه درگیر و اثر کلی را توضیح دهید و پیش از ارسال مدارک حساس، مسیر محرمانه را هماهنگ کنید.

Do not send passwords, live tokens, private keys, complete license keys or production databases. Use minimal, sanitized examples. This repository does not operate a paid bug bounty or promise a fixed response time.

رمز، توکن فعال، کلید خصوصی، کلید کامل لایسنس یا دیتابیس واقعی ارسال نکنید. نمونه‌ها باید حداقلی و پاک‌سازی‌شده باشند.
