## English

The latest product version is **1.9.3**. GitHub installer releases are being prepared. No installer assets have been published in this repository yet. Product version numbers are not a claim that a corresponding GitHub release is already available.

Use the [official download page](https://anbarkhan.ir/download/) for current distribution information. Check [GitHub Releases](https://github.com/codiatorstudio/anbarkhan-releases/releases) for packages when published.

Before upgrading, export a backup and keep a copy outside the application folder. Contact support before downgrading: an older application may not support a database upgraded by a newer version.

When packages become available, download installers from release **Assets**. GitHub's automatic **Source code (zip/tar.gz)** archives contain this documentation repository, not the Windows application.
